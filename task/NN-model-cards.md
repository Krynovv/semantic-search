# Задание: карточки моделей
Круг ревью: 0 из 2

## Цель
Создать `results/MODELS.md` с карточкой на каждую обученную модель.

## Контекст
- Блок «Сейчас» и записи про обучение в `kursovaya-tex/research-log.md`.
- `kursovaya-tex/results/*.json`, `*.csv` (если есть метрики; большие файлы не открывать, смотреть `head -n 5`).
- Модели лежат в `/mnt/proj/proj/study/data/semsearch_download/` (`ru-only`, `mix-en`).

## Требования
1. Для каждой модели заполнить шаблон из `results/MODELS.md` (шаблон ниже).
2. Метрики и параметры брать только из файлов. Нет данных: писать «нет данных», не выдумывать.
3. Размер весов получить командой `du -sh`, а не чтением файла.

## Ограничения
- Файлы `*.safetensors`, `tokenizer.json`, `*.jsonl` инструментом чтения не открывать. Разрешено читать только маленькие конфиги (`config.json`).

## Критерии готовности
В `results/MODELS.md` есть раздел на каждую модель, нет выдуманных чисел, пути указаны.

## Проверка
`ls ~/data/study-ensemble/semsearch_download` и `du -sh` по каждой папке (приложить вывод).
